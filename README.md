## Мета

Навчитися використовувати систему контролю версій Git для захисту цілісності даних.

## Що демонструє репозиторій

1. Створення гілок і фіксацію змін (`branch`, `checkout`, `commit`).
2. Синхронізацію з віддаленим репозиторієм (`push`, `fetch`, `pull`).
3. Злиття гілок через pull request і локально (`merge`).

## Основні команди

| Команда | Призначення |
|---------|-------------|
| `git clone <url>` | отримати копію репозиторію з усією історією |
| `git add <файл>` | додати зміни до індексу |
| `git commit -m "..."` | зафіксувати знімок стану |
| `git push` | надіслати коміти у віддалений репозиторій |
| `git pull` | отримати та злити віддалені зміни |
